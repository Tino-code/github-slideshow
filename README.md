# KTU-Bot

AI-powered chatbot for Koforidua Technical University (KTU) to facilitate access to university information and enhance student support services.

## Project Structure

-   `frontend/`: Contains the React.js application for the chatbot interface.
-   `backend/`: Contains the Python (Flask) application for the chatbot logic and API.

## Tech Stack

-   **AI & NLP**: OpenAI GPT or similar LLMs
-   **Backend**: Python (Flask)
-   **Frontend**: React.js
-   **Database**: Astro DB (as per project description, will be integrated later)
